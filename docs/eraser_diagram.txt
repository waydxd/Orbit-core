// Connections

// Client to Gateway
Flutter App > API Gateway: HTTPS REST API

// Gateway to Microservices
API Gateway > User Service: Route auth requests
API Gateway > Calendar Task Service: Route planning requests
API Gateway > AI Service: Route AI requests
API Gateway > Location Service: Route location requests

// Microservices inter-communication
Calendar Task Service > User Service: Validate user exists
AI Service > User Service: Get user preferences
AI Service > Calendar Task Service: Fetch tasks/events for RAG
Location Service > Calendar Task Service: Create location events
AI Service > Location Service: Get location context

// Microservices to Data Layer
User Service > PostgreSQL: Store user data
Calendar Task Service > PostgreSQL: Store tasks/events
AI Service > PostgreSQL: Store AI logs
Location Service > PostgreSQL: Store GPS data
AI Service > MongoDB: Store documents, vector embeddings

// Cache Connections
User Service > Redis: Cache user sessions
Calendar Task Service > Redis: Cache recent tasks
API Gateway > Redis: Rate limiting

// External API Connections
AI Service > Gemini API: Send chat requests
AI Service > vLLM Server: LangChain calls
AI Service > TensorFlow Recommenders: Train/run ML models
Location Service > Google Maps: Geocoding requests
User Service > Email Service: Send verification emails

// Client-Side AI
Flutter App > Google ML Kit: Process images locally

// File Storage
Flutter App > Object Storage: Upload images/files

// Future Enhancements (dashed)
