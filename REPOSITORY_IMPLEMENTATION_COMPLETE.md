## Database Architecture

### SQL-First Approach
All repositories use PostgreSQL with:
- **Context-based timeouts** - Prevent hanging requests
- **Parameterized queries** - Protection against SQL injection
- **Error wrapping** - Detailed error messages with context
- **Proper indexing** - Optimized for common queries

### Key Database Features
1. **UUID Primary Keys** - Generated by PostgreSQL
2. **Timestamp Tracking** - created_at and updated_at with auto-updates
3. **Foreign Keys** - Referential integrity with ON DELETE CASCADE
4. **Indexes** - On frequently filtered columns (user_id, timestamps, status)
5. **Constraints** - Unique constraints on user_id + service_name for integrations

## Usage Pattern

```go
// Initialize database connection
db, err := database.Connect(connectionString)
if err != nil {
    log.Fatal(err)
}
defer db.Close()

// Create repositories
authRepo := auth.NewSQLRepository(db)
eventRepo := calendar.NewSQLEventRepository(db)
taskRepo := calendar.NewSQLTaskRepository(db)
locationRepo := location.NewSQLRepository(db)
integrationRepo := integration.NewSQLRepository(db)

// Create services with repositories
authService := auth.NewService(config, logger, authRepo)
calendarService := calendar.NewService(config, logger, eventRepo, taskRepo)
locationService := location.NewService(config, logger, locationRepo)
integrationService := integration.NewService(config, logger, integrationRepo)

// Register routes
authService.RegisterRoutes(router)
calendarService.RegisterRoutes(router)
locationService.RegisterRoutes(router)
integrationService.RegisterRoutes(router)
```

## Security Features

1. **Password Hashing**
   - Argon2id algorithm
   - 2^16 memory cost
   - 4 parallelism
   - Random salt per user

2. **Token Management**
   - Token hashing before storage
   - Session expiration validation
   - TTL-based cleanup

3. **API Key Protection**
   - Encrypted storage (placeholder for production)
   - Not returned in list operations

4. **Database Security**
   - Parameterized queries (no SQL injection)
   - Foreign key constraints
   - Cascading deletes for data consistency
